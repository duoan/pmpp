GROUP_M 到底为什么这样排？

这个动画只演示一件事：普通顺序是横着算，GROUP 顺序是把几行绑成一组后竖着算。 这样相邻 program 更容易使用同一块 B[:, n]，也就更容易命中 L2 cache。

6. 你要记住的原因

普通顺序：C[0,0] -> C[0,1] -> C[0,2]，B 的列一直换，所以刚读过的 B 很快不用。

GROUP 顺序：C[0,0] -> C[1,0]，这两个都用 B[:,0]。 第二个 program 很可能直接从 L2 cache 拿到刚才那块 B。 

普通:   C[0,0], C[0,1], C[0,2], C[1,0], ...
用 B:   B[:,0], B[:,1], B[:,2], B[:,0], ...

GROUP:  C[0,0], C[1,0], C[0,1], C[1,1], ...
用 B:   B[:,0], B[:,0], B[:,1], B[:,1], ...

所以 GROUP 的重点不是算得不一样，而是访问顺序更容易复用 B。
